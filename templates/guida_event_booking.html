🎯 1. Introduzione

EventBooking e' un'applicazione web per la gestione e prenotazione di posti per eventi in sale conferenza, teatri, cinema o spazi simili.

Caratteristiche principali

  • Calendario interattivo con navigazione per anno e mese
  • Gestione multi-sale con layout personalizzabili (file x colonne)
  • Prenotazione visuale dei posti con colori per stato
  • Notifiche email automatiche per conferme prenotazioni
  • Ricerca avanzata prenotazioni per amministratori
  • Database cloud su Neon PostgreSQL
  • Installabile come app (PWA) su smartphone e desktop, con icona propria e funzionamento offline della shell dell'app
  • Recupero password via email in caso di smarrimento credenziali

Tipologie di utente

RuoloDescrizionePermessi
Utente Partecipante agli eventi Visualizza calendario, prenota posti, riceve email di conferma
Admin Organizzatore / Gestore Crea sale, crea eventi, gestisce prenotazioni, ricerca partecipanti, vede nomi sui posti

Utente 2.1 Registrazione e Login

Registrazione

1

Accedi alla pagina di registrazione

Clicca su Registrati nella barra di navigazione.

2

Compila il modulo

Inserisci:

  • Nome e Cognome: il tuo nome completo
  • Username: solo lettere e numeri, minimo 3 caratteri. Deve essere univoco e puoi usarlo al posto dell'email per accedere
  • Email: indirizzo valido (serve per le conferme e per il recupero password)

3

Nota: Il primo account admin deve essere creato manualmente nel database o tramite procedura dedicata.

Login

Accesso al calendario

Password dimenticata? Vedi la sezione 2.2 Password Dimenticata.

Utente 2.2 Password Dimenticata

Se non ricordi la password, puoi reimpostarla in autonomia tramite email.

1

Clicca "Password dimenticata?"

Nella pagina di Login, clicca il link Password dimenticata? sotto il pulsante Accedi.

2

Inserisci la tua email

Digita l'indirizzo email usato in fase di registrazione e clicca Invia Link di Reset.

3

Controlla la posta

Riceverai un'email con un link univoco e temporaneo per reimpostare la password. Controlla anche la cartella Spam se non la vedi in pochi minuti.

4

Imposta la nuova password

Clicca il link ricevuto via email, inserisci la nuova password (minimo 8 caratteri) e confermala nel secondo campo.

Nota: il link di reset è valido una sola volta ed è legato a un token univoco: se scade o è già stato usato, dovrai richiederne uno nuovo dalla pagina "Password dimenticata?".

Utente 2.4 Prenotare un Posto

La prenotazione avviene tramite una mappa visiva della sala, dove ogni posto e' rappresentato da un riquadro colorato.

Legenda colori

ColoreStatoSignificato
Bianco Libero Posto disponibile, cliccabile
Arancione Riservato Posto temporaneamente bloccato dall'amministratore

Procedura di prenotazione

1

Seleziona l'evento

Dal calendario, clicca su una data con evento e poi su Prenota.

2

Scegli i posti

Clicca sui posti bianchi (liberi) per selezionarli. Diventeranno verdi acqua.

Puoi selezionare uno o piu' posti contemporaneamente.

Per deselezionare un posto, cliccalo di nuovo.

3

Conferma

Clicca Conferma Prenotazione. Si aprirà una finestra che chiede il nome della prenotazione: di default è precompilato con il tuo nome e cognome, ma puoi modificarlo (ad es. per prenotare a nome di un'altra persona o di un gruppo).

Premi Conferma nella finestra (o Invio) per completare. I posti diventeranno azzurri (prenotati) e mostreranno il nome scelto.

4

Email di conferma

Riceverai un'email all'indirizzo registrato con i dettagli della prenotazione:

  • Nome dell'evento
  • Data e ora
  • Sala
  • Posti prenotati (es. A1, A2, B3)
Attenzione: Una volta confermata, la prenotazione non puo' essere annullata direttamente dall'utente. Contatta un amministratore per modifiche.

Installazione passo-passo

1

Scarica il progetto

Estrai l'archivio in una cartella sul tuo PC.

2

Crea l'ambiente virtuale

cd event_booking_app
python -m venv venv

venv\Scriptsctivate

Su Linux/Mac:

source venv/bin/activate
3

Installa le dipendenze

pip install -r requirements.txt
4

Nella stessa cartella di app.py, crea un file chiamato .env:

SECRET_KEY=una-chiave-sicura-lunga-e-casuale-123456789

MAIL_SERVER=smtp.gmail.com

Admin 3.5 Gestione Sale

Le sale sono gli spazi fisici dove si tengono gli eventi. Si gestiscono dalla pagina 🏛️ Sale in navbar.

Creare una sala

1

Vai su "🏛️ Sale"

Compila il form "Nuova Sala": nome, indirizzo (opzionale), descrizione (opzionale), capienza massima, tetto di overbooking, email amministratori per notifiche.

2

Capienza massima e overbooking

La capienza massima è il limite normale di posti per quella sala. Il tetto di overbooking è quanti posti extra oltre quel limite si possono eventualmente concedere (0 = overbooking disabilitato per questa sala) — va comunque poi abilitato esplicitamente su ogni singolo Layout Posti o Evento, non si applica mai automaticamente.

3

Salva

Clicca Crea Sala. La sala comparirà subito nell'elenco e sarà selezionabile in Layout Posti e in Creazione Evento.

Modificare o eliminare una sala

Dall'elenco, Modifica precompila il form con i dati esistenti. Elimina è bloccato se la sala ha eventi o layout posti collegati — vanno rimossi prima quelli, per evitare cancellazioni accidentali di prenotazioni.

Nota: se riduci la capienza massima o il tetto di overbooking sotto la dimensione di un layout già esistente per quella sala, il layout esistente non viene toccato, ma riceverai un avviso — non potrai crearne di nuovi sopra il nuovo limite finché non lo alzi di nuovo.

Admin 3.6 Generi Evento

I generi (es. "Concerto", "Conferenza", "Teatro") permettono di avere layout posti diversi per tipologia di evento nella stessa sala — ad esempio meno file con più corridoi per un concerto, tutte le file piene per una conferenza. Si gestiscono dalla pagina Gestione Generi (raggiungibile dal fondo della pagina Layout Posti).

1

Crea un genere

Nome (obbligatorio) e descrizione (opzionale). È un'etichetta libera, associabile poi a uno o più Layout Posti.

Nota: il genere è opzionale — un Layout Posti può anche non avere nessun genere associato ("layout generico per la sala"), utile se non ti serve questa distinzione.

Eliminazione: bloccata se il genere è ancora usato da uno o più layout esistenti — scollega prima quei layout.

Admin 3.7 Layout Posti

Un Layout Posti è una disposizione di sala riutilizzabile (file, colonne, corridoi) salvata una volta e richiamabile ogni volta che crei un evento, invece di reinserire gli stessi numeri manualmente. Si gestisce dalla pagina 🪑 Layout Posti in navbar.

Creare un layout

1

Seleziona la sala

Dal menu a tendina in alto. Comparirà il form per creare un nuovo layout per quella sala specifica.

2

Configura

Nome del layout (es. "Platea intera"), genere opzionale, numero file e colonne, corridoi (stessa sintassi già vista in creazione evento: numeri separati da virgola).

3

Overbooking e Default

Spunta "Abilita overbooking" solo se vuoi che questo specifico layout possa superare la capienza normale della sala (fino al tetto impostato sulla sala stessa — se il tetto è 0, il checkbox non avrà effetto). Spunta "Imposta come layout di default" se vuoi che venga proposto automaticamente in fase di creazione evento per quella sala/genere — un solo layout può essere default per ogni combinazione sala+genere, impostarne uno nuovo toglie automaticamente il flag al precedente.

Gestire i layout esistenti

Dalla tabella puoi impostare come default un layout diverso, oppure eliminarlo — bloccato se è già stato usato per creare uno o più eventi (per non rompere la tracciabilità di eventi già esistenti).

Perché conviene usarli: una volta configurati i layout per una sala, la creazione di un nuovo evento diventa molto più rapida — basta scegliere il layout giusto invece di reinserire file/colonne/corridoi ogni volta.

Procedura

1

Seleziona la data

2

Clicca "Crea Evento"

Verrai reindirizzato al modulo di creazione con la data precompilata.

3

Compila il modulo

CampoDescrizione

Numero ColonneQuante colonne per fila
Nome EventoTitolo dell'evento

Se i posti creati superano la capacita' della sala, l'evento non verra' creato.

Clicca Crea Evento. I posti verranno generati automaticamente con file A, B, C... e colonne numerate.

[Screenshot: Modulo creazione evento]

L'integrazione diretta "scegli layout dal menu" nel modulo di creazione evento è prevista in un prossimo aggiornamento.

Layout della sala

Campi ricercabili: nome cognome, email, username, nome prenotazione, fila e colonna del posto (es. "A1").

Admin 3.11 Posti Abbonato

I posti Abbonato sono una tipologia speciale di posto riservato, gestibile esclusivamente dagli amministratori. Funzionano in modo simile ai posti "Riservati" ma con un colore distintivo (viola) per identificarli facilmente nella mappa della sala.

Caratteristiche

  • Visibilità: visibili a tutti gli utenti con colore viola
  • Prenotabilità: gli utenti normali non possono prenotarli
  • Gestione: solo gli admin possono creare o cancellare posti abbonato
  • Email: le notifiche di cancellazione funzionano come per le altre prenotazioni

Procedura per abbonare posti

1

Seleziona l'evento

Dal calendario, accedi alla pagina di prenotazione dell'evento desiderato.

2

Seleziona i posti liberi

Clicca sui posti bianchi (liberi) che vuoi riservare agli abbonati.

3

Clicca "Abbona Posti"

Il pulsante viola 🎫 Abbona Posti appare solo agli admin. Cliccalo per confermare.

4

Inserisci il nome (opzionale)

Puoi personalizzare il nome dell'abbonamento, oppure lasciare il default "Abbonato".

Cancellare posti abbonato

Gli admin possono cancellare i posti abbonato cliccandoli (apparirà l'animazione rossa di selezione per cancellazione) e poi premendo 🗑️ Cancella Selezionati.

Nota: I posti abbonato condividono la logica dei posti riservati ma usano lo stato abbonato nel database e il colore #8b5cf6 (viola) nell'interfaccia.

Admin 3.12 Riservare Posti

I posti Riservati permettono di bloccare temporaneamente uno o più posti senza associarli a una prenotazione utente vera e propria (es. per staff, ospiti, posti tecnici).

Procedura per riservare posti

1

Seleziona l'evento

Dal calendario, accedi alla pagina di prenotazione dell'evento desiderato (anche come admin).

2

Seleziona i posti liberi

Clicca sui posti bianchi (liberi) che vuoi riservare. Diventeranno verdi acqua (in selezione).

3

Clicca "🔒 Riserva Posti"

Il pulsante arancione Riserva Posti appare solo agli admin, accanto a "Conferma Prenotazione".

4

Inserisci il nome (opzionale)

Puoi personalizzare il nome della riserva, oppure lasciare il default "Riservato".

Nota: i posti riservati sono visibili a tutti gli utenti in arancione e non sono prenotabili dagli utenti normali. Solo un admin può cancellarli (vedi sezione successiva).

Admin 3.13 Cancellare Prenotazioni

Gli amministratori possono cancellare posti prenotati, riservati o abbonati direttamente dalla mappa della sala.

Procedura di cancellazione

1

Accedi alla pagina di prenotazione

Dal calendario, clicca su Prenota per l'evento desiderato (anche come admin).

2

Seleziona i posti da cancellare

Clicca sui posti azzurri (prenotati), arancioni (riservati) o viola (abbonati) che vuoi cancellare.

I posti selezionati per la cancellazione diventeranno rossi lampeggianti con un'animazione pulsante.

3

Conferma la cancellazione

Clicca il pulsante 🗑️ Cancella Selezionati. Apparirà una finestra di conferma con il numero di posti da cancellare.

Se stai cancellando sia posti prenotati che riservati, il messaggio indicherà la suddivisione.

4

Notifiche email

Dopo la cancellazione, l'utente proprietario della prenotazione riceverà un'email di notifica con:

  • Nome dell'evento e data
  • Posti cancellati (es. A1, A2, B3)
  • Nome dell'amministratore che ha effettuato l'operazione

Gli altri amministratori della sala riceveranno una notifica email della cancellazione.

Cancellare un evento completo

Nella pagina di Gestione Evento o nel modale del calendario (doppio click su data), gli admin possono eliminare l'intero evento:

Attenzione: L'eliminazione di un evento cancella tutte le prenotazioni associate e i posti. Questa azione è irreversibile.
1

Clicca "Elimina Evento"

Nella pagina di gestione o nel modale del calendario, clicca il pulsante rosso 🗑️ Elimina Evento.

2

Conferma

Apparirà un messaggio di conferma. Clicca OK per procedere.

L'evento e tutte le prenotazioni associate verranno rimosse definitivamente.

Admin 4.1 Overbooking — come funziona

L'overbooking permette di superare la capienza normale di una sala in casi eccezionali, ma è sempre a due livelli, mai automatico:

LivelloDove si impostaSignificato
Tetto massimo Campo "Tetto overbooking" in Gestione Sale Quanto è possibile al massimo per quella sala (0 = overbooking impossibile, a prescindere da tutto il resto)
Attivazione esplicita Checkbox "Abilita overbooking" in Layout Posti (e in futuro anche in Creazione Evento) Se non spuntato, il limite resta quello normale anche se la sala consente overbooking
Esempio: una sala ha capienza 100 e tetto overbooking 20 (quindi fino a 120 in totale). Se crei un layout senza spuntare "Abilita overbooking", resti comunque vincolato a 100 posti. Solo spuntando la casella potrai arrivare fino a 120.

❓ 5. FAQ e Troubleshooting

Problemi comuni

🟡 Non vedo il pulsante "Crea Evento"

Il pulsante appare solo agli utenti con tipo admin.

🟡 Non posso prenotare posti

  • L'evento e' in una data passata
  • I posti sono gia' tutti prenotati
  • Non hai effettuato il login

🟡 Non ricevo l'email di conferma o di reset password

  • Controlla la cartella Spam o Promozioni
  • Verifica di aver inserito l'email corretta in fase di registrazione
  • Se il problema persiste, contatta l'amministratore del sistema
{% if current_user.is_admin() %}

🔴 L'applicazione non si avvia

Verifica:

  • L'ambiente virtuale e' attivo?
  • Hai installato tutte le dipendenze?
  • La porta 5000 e' libera?

🔴 Errore di connessione al database

Verifica:

  • La stringa DATABASE_URL nel file .env e' corretta?
  • Hai incluso ?sslmode=require?
  • Hai eseguito /init-db almeno una volta?

🔴 Le email non arrivano a nessun utente

Verifica lato server:

  • Stai usando una App Password Gmail?
  • Le credenziali nel .env sono corrette?

🟢 Come faccio il backup del database?

pg_dump "DATABASE_URL" > backup.sql

🟢 Posso usare un altro database?

Si', modifica la stringa DATABASE_URL. Compatibile con PostgreSQL, MySQL, SQLite.
